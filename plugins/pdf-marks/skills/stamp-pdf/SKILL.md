# Печать в PDF

Скрипт `stamp.py` (PyMuPDF + Pillow) кладёт заранее сохранённый PNG печати на блок подписи. Координаты руками указывать не надо — блок ищется по тексту, тем же способом, что и в соседнем скилле `sign-pdf`.

Пути к скриптам: `${CLAUDE_PLUGIN_ROOT}/skills/stamp-pdf/scripts/{stamp.py,prep.py}`. Дальше в примерах — коротко.

Порядок работы с документом: сначала подпись (`sign-pdf`), потом печать по подписанному файлу. Печать по умолчанию садится внахлёст на подпись — как её ставят рукой.

## Быстрый старт

```bash
python3 stamp.py <файл.pdf> -s acme --preview
```

Результат: `<файл>-stamped.pdf` рядом с исходником + `<файл>-stamped-preview.png` — кроп области печати.

**Превью обязательно открыть через Read и проверить глазами**, прежде чем отчитываться пользователю: печать не должна закрывать имя, должность или сумму. Если закрыла — сдвинуть (`--place left`, `--x/--y`) или уменьшить (`--size`).

Оригинал никогда не перезаписывается.

## Где лежат печати

```bash
python3 stamp.py --list
```

Хранилище — папка пользователя, не каталог приложения:

1. `$STAMPS_DIR` — если переменная задана (несколько путей через `:`);
2. иначе `~/Documents/Stamps/`.

Имя файла = имя печати: `acme.png` → `-s acme`.

## Как сделать печать из фотографии

Печать обычно есть только на бумаге. `prep.py` превращает снимок в PNG с прозрачным фоном:

```bash
python3 prep.py ~/Downloads/IMG_1234.HEIC ~/Documents/Stamps/acme.png --rotate 90
```

- `--rotate` — на сколько градусов **по часовой** довернуть снимок, чтобы текст читался нормально. Определить по фото и передать явно;
- HEIC с айфона читается через `sips` (macOS), отдельных зависимостей не нужно;
- освещение выравнивается автоматически, бумага вычитается, цвет чернил берётся из самого снимка;
- печать находится как самый большой сгусток чернил, не касающийся края кадра. Стол, тень и край листа отсекаются именно по этому признаку — поэтому снимать надо так, чтобы печать не упиралась в границу кадра;
- `--size 1200` — если нужен PNG крупнее (по умолчанию 1000 px по длинной стороне).

Результат проверить глазами через Read, прежде чем регистрировать. Снимать лучше при рассеянном свете, без вспышки и без резкой тени поперёк оттиска.

Положить готовый PNG в хранилище можно и через скрипт:

```bash
python3 stamp.py --register ~/Downloads/acme-clean.png -s acme
```

## Как ищется место

1. Находит **строку имени** в скобках — `(Jane Doe)` — ниже верхней трети страницы, самую нижнюю из таких.
2. Берёт **линию подписи** над ней: ряд подчёркиваний текстом или нарисованную векторную линию.
3. Сажает печать так, чтобы она наезжала на левый край подписи и пересекала линию — центр смещён вправо от начала линии на треть диаметра и приподнят над ней.

4. Низ печати прижимается к строке имени: оттиск пересекает линию, но имя и должность под ней остаются читаемыми.

Умолчания: диаметр 115 pt (≈ 40 мм, типовой размер круглой печати), прозрачность 0.85, наклон −6° (против часовой). Наклон и прозрачность нужны, чтобы оттиск не выглядел вставленной картинкой и не съедал текст под собой.

Слева от блока подписи печать не ставится: блок и так начинается от поля страницы, места там нет. Поэтому «не перекрывать» — это `--place beside`, справа.

## Куда ещё можно поставить

| Флаг | Что делает |
|---|---|
| `--place over` | внахлёст на подпись — по умолчанию |
| `--place beside` | справа от линии подписи, ничего не перекрывая |
| `--place corner` | правый нижний угол страницы, блок подписи игнорируется |
| `--anchor "(Имя Фамилия)"` | якорная строка дословно, если на странице несколько блоков |
| `--x 75 --y 642` | координаты вручную, в points, начало отсчёта в левом верхнем углу |
| `--page N` | если печать не на первой странице |

Одной командой обрабатывается одна страница. Нужно несколько — запустить по разу на страницу, каждый раз по результату предыдущего запуска.

## Остальные флаги

| Флаг | Что делает |
|---|---|
| `--size 90` | диаметр печати в points |
| `--opacity 0.7` | сильнее просвечивает текст под печатью |
| `--rotate 0` | без наклона |
| `--output DIR` | папка для результата (по умолчанию — рядом с исходником) |
| `--suffix=-sealed` | другой суффикс имени файла (через `=`, иначе argparse примет значение за флаг) |
| `--force` | перезаписать существующий результат |
| `--image путь.png` | взять PNG напрямую, мимо хранилища |

Несколько файлов можно передать одной командой — все штампуются одной печатью.

## Зависимости

`pip3 install pymupdf pillow` (для `prep.py` дополнительно `numpy`). Если чего-то нет, скрипт скажет об этом первой же строкой.

## Границы

- Это **визуальный оттиск**, а не электронная подпись и не нотариальное заверение. Юридическую силу даёт подписант, а не картинка.
- Ставить печать только по прямой просьбе того, кто вправе ею распоряжаться. Не проставлять «заодно» в документы, о которых не просили.
- **Печать компании — подделываемый актив.** PNG живёт только в папке пользователя: не коммитить в репозитории, не класть внутрь плагина, не прикладывать к переписке отдельным файлом.
