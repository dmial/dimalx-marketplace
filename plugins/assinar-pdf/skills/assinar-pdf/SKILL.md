# Подпись в PDF

Скрипт `assinar.py` (PyMuPDF) кладёт заранее сохранённый PNG подписи в нужное место страницы. Координаты руками указывать не надо — блок подписи ищется по тексту.

Путь к скрипту: `${CLAUDE_PLUGIN_ROOT}/skills/assinar-pdf/scripts/assinar.py`. Дальше в примерах он сокращён до `assinar.py`.

## Быстрый старт

```bash
python3 assinar.py <файл.pdf> -p ana --preview
```

Результат: `<файл>-assinada.pdf` рядом с исходником + `<файл>-assinada-preview.png` — кроп области подписи.

**Превью обязательно открыть через Read и проверить глазами, что подпись села на линию**, прежде чем отчитываться пользователю. Автопоиск блока подписи надёжен, но не идеален.

Оригинал никогда не перезаписывается.

## Где лежат подписи

```bash
python3 assinar.py --listar
```

Хранилище — папка пользователя, не каталог приложения:

1. `$SIGNATURES_DIR` — если переменная задана (несколько путей через `:`);
2. иначе `~/Documents/Signatures/`, затем `~/Documents/Assinaturas/`.

Имя файла = имя подписи: `ana.png` → `-p ana`.

Добавить нового человека:

```bash
python3 assinar.py --registar ~/Downloads/scan.png -p ana
```

Формат: PNG с прозрачным фоном, подпись обрезана по краям. Чернила лучше оставить как на бумаге (синие/чёрные) — при печати читается естественнее.

Если у человека две версии — обычная и затемнённая для печати — назвать вторую `<имя>-escura.png`. Скрипт по умолчанию берёт затемнённую, флаг `--clara` заставляет взять базовую.

Поддерживается и JSON-формат расширения pdf-toolkit для Claude Desktop (base64 внутри). Чтобы брать подписи оттуда: `SIGNATURES_DIR=~/.pdf-toolkit-files/signatures`.

## Как ищется место

1. Находит **строку имени** в скобках — `(Jane Doe)` — ниже верхней трети страницы. Если таких несколько, берёт самую нижнюю.
2. Смотрит, есть ли над ней **линия для подписи**: либо ряд подчёркиваний текстом (`_____`), либо нарисованная векторная линия. Если есть — сажает подпись на неё, с лёгким заходом хвостов ниже линии.
3. Если линии нет — центрирует подпись в пустоте между строкой имени и предыдущей строкой текста.
4. Ширина по умолчанию 165 pt; если промежуток тесный, автоматически уменьшает, чтобы не наехать на текст.

## Когда автопоиск не сработал

- `--ancora "(Имя Фамилия)"` — указать якорную строку дословно (если имя не в скобках или на странице несколько блоков);
- `--x 75 --y 642` — задать координаты вручную, в points, начало отсчёта в левом верхнем углу;
- `--pagina N` — если подпись не на первой странице.

Посмотреть, что вообще есть внизу страницы:

```bash
python3 -c "
import fitz; d=fitz.open('файл.pdf'); p=d[0]
for w in p.get_text('words'):
    if w[1] > p.rect.height*0.6: print([round(x) for x in w[:4]], repr(w[4]))
"
```

## Остальные флаги

| Флаг | Что делает |
|---|---|
| `--largura 200` | ширина подписи в points |
| `--saida DIR` | папка для результата (по умолчанию — рядом с исходником) |
| `--sufixo -signed` | другой суффикс имени файла |
| `--forcar` | перезаписать существующий результат |
| `--imagem путь.png` | взять PNG напрямую, мимо хранилища |

Несколько файлов можно передать одной командой — все подписываются одной подписью.

## Зависимость

Нужен PyMuPDF: `pip3 install pymupdf`. Если его нет, скрипт скажет об этом первой же строкой.

## Границы

- Это **визуальный штамп**, а не квалифицированная электронная подпись. Там, где нужна QES, не годится.
- Ставить подпись только по прямой просьбе владельца подписи или того, кто действует от его имени. Не проставлять «заодно» в документы, о которых не просили.
- Подписи никогда не коммитить в репозитории и не класть внутрь плагина — они живут только в папке пользователя.
